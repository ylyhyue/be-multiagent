# 营商标准化多智能体系统 · BE-MultiAgent

> 一套面向「营商环境」主题赛事的**开源多智能体系统**——像豆包/自定义 GPT 一样，可下载、复制 System Prompt 到 AI 使用，也能一键部署到 GitHub。

## 一、这是什么

围绕两场营商环境主题赛事，本仓库提供 **1 个主调度 + 2 个子智能体** 的完整定义。每个子智能体同时具备「参赛辅导（Builder）」与「评审打分（Judge）」双模式——既能当参赛团队的"陪练+代笔"，也能当主办方的"AI 评委"，一套定义、两种用法。

| 智能体 | 对应赛事 | 核心抓手 |
|---|---|---|
| **主调度 Orchestrator** | 在两场赛事间做路由与协同（不生产内容） | 意图识别、分发、跨赛事评分联动 |
| **Agent1 · 营商数擎 DataBE** | 2026 中国信息协会数据要素应用创新大赛 ·「数据要素赋能营商环境创新应用赛道」 | 数据要素（共享/治理/授权运营） |
| **Agent2 · 满意标尺 SatBE** | 「企业满意看营商」创新实践挑战赛 | 企业满意度（感受/需求/效果导向） |

## 二、系统架构

```
                        ┌─────────────────────────────┐
   用户需求 ──────────▶ │   主调度 Orchestrator (@主调度) │
                        │  意图识别 / 路由 / 评分联动     │
                        └───────────┬───────────┬───────┘
                                    │           │
                      赛事=数据要素  │           │ 赛事=企业满意
                                    ▼           ▼
                       ┌────────────────┐   ┌────────────────┐
                       │ Agent1 DataBE  │   │ Agent2 SatBE   │
                       │ Builder+Judge  │   │ Builder+Judge  │
                       └────────────────┘   └────────────────┘

   跨赛事/对比需求 → 主调度并行 A1+A2 → 出「跨赛道联动评估」报告
```

## 三、三种使用方式（任选）

### 方式 1 · 复制 System Prompt 到任意 AI（最简单，零门槛）
1. 打开 `agents/` 下对应文件，复制其中 `SYSTEM PROMPT（复制以下区块）` 整段。
2. 粘贴到任意支持自定义 system prompt 的对话式 AI（ChatGPT / Claude / 豆包 / Gemini / 通义 / Kimi / WorkBuddy 等）。
3. 开始对话即可。

### 方式 2 · 在 WorkBuddy 注册为「专家」（一键调用）
将 `prompts/*.txt` 的 System Prompt 注册为专家，即可在对话中 `@主调度` / `@营商数擎` / `@满意标尺` 直接调用。

### 方式 3 · 部署到 GitHub / 本地复用
```bash
git clone <本仓库地址> BE-MultiAgent
# 或直接下载 ZIP，按需取用 agents/ 与 prompts/ 中的文件
```
任意项目、任意团队皆可 fork、修改、再分发（见 [LICENSE](LICENSE)）。

## 五、评审 Rubric 速查（建议版）

> ⚠️ 两场赛事官方**未公布细项权重评分表**，以下权重均基于官方"申报条件/赛道聚焦/赛程"反推的**建议版**，主办方公布终版后请同步微调。

### Agent1 · DataBE（100 分，5 维）
| 维度 | 权重 |
|---|---|
| 数据要素应用深度 | 25% |
| 创新性 | 20% |
| 实效性与成效 | 25% |
| 示范与可推广性 | 15% |
| 材料与表达 | 15% |

### Agent2 · SatBE（100 分，7 维）
| 维度 | 权重 |
|---|---|
| 政策符合与示范意义 | 15% |
| 企业满意度导向 | 25% |
| 创新性 | 15% |
| 实效（可量化可感知） | 25% |
| 真实性与可核验 | 10% |
| 示范性推广价值 | 5% |
| 路演现场表现（仅答辩） | 5% |

### 跨赛道联动
- 实效性 25% 两表完全一致，是跨赛道对标主轴。
- 数据要素应用深度（A1 独 25%）与企业满意度导向（A2 独 25%）为各自灵魂维度。
- 跨赛道综合分（默认等权）：`综合分 = 0.5 × A1 + 0.5 × A2`（权重可调）。

## 六、关键规则
- **利益冲突拦截（硬性）**：同一作品在同一赛道不得既做参赛指导又做该赛道评委。
- **评分真实性**：所有打分基于真实材料，缺数据即索要，绝不编造指标。
- **一致性**：两子智能体共用赛道知识库与 rubric，参赛即按评审标准反向打磨。
