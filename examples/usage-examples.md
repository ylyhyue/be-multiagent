# 使用示例（测试用例 T1~T4）

> 以下为系统四类标准流程的触发指令与预期行为，可直接复制到已加载对应 System Prompt 的 AI 中验证。

---

## T1 · 参赛材料撰写（Builder → Agent1）

**触发指令**（加载 `agent1-data-be.txt` 后）：
```
帮我写一份数据要素赛道赛题二的申报书。背景：某高新区用产业链数据共享做融资撮合，已对接12家银行、归集企业信用数据3.2万条，中小微企业获贷时长从21天降到9天，获贷率提升18%。
```

**预期行为**：出选题卡（赛题二·场景创新）→ 按"数据四问"组织方案 → 量化成效带基线 → 生成申报书 → 用 A1 rubric 出《自检清单》。

**验收点**：①含数据来源/治理/赋能/闭环四问；②量化指标均带"基线→现状"；③结构合规；④自检标注薄弱维度（如"示范可推广"待补）。

---

## T2 · 赛事评审打分（Judge → Agent2）

**触发指令**（加载 `agent2-sat-be.txt` 后）：
```
评审以下作品（助企服务与要素保障赛道）：某地"企业诉求一键响应"平台，整合12345与政务热线，平均响应2小时，办结率92%，企业满意度从81%升至94%，附10家企业访谈实录。
```

**预期行为**：按 7 维 rubric 逐维打分，每条给证据与改进建议，输出标准评审表与晋级/待打磨/淘汰结论。

**验收点**：①七维度齐全且权重正确（满意度25/实效25/政策15/创新15/真实10/示范5/现场5）；②每条含证据；③有总分与一句话总评；④结论明确。

---

## T3 · 路演答辩辅导（红蓝对抗 → 主调度路由到 Agent2）

**触发指令**（加载 `main-orchestrator.txt` 后）：
```
路演辅导：用满意标尺赛道（助企）这份"企业诉求一键响应"材料，给我3分钟路演稿 + 答辩预判，并模拟评委挑刺。
```

**预期行为**：路由→Agent2；蓝队出 3 分钟路演稿 + 分镜；红队针对 rubric 弱点（如"真实性可核验"证据链）生成≥5 条毒舌追问；蓝队补应答话术。

**验收点**：①含时间轴（≤3 分钟）；②≥5 条预判问题；③每条问题配应答话术；④点明最可能被追问的维度。

---

## T4 · 跨赛道联动评估（主调度并行 A1+A2）

**触发指令**（加载 `main-orchestrator.txt` 后）：
```
用两个赛道分别评这份"政策免申即享（数据比对自动兑现惠企补贴）"实践并给联合分。
```

**预期行为**：并行 A1+A2 Judge；出跨赛道联动评估。

**验收点**：①含 A1、A2 各自百分分；②含跨赛道综合分（0.5/0.5）；③含实效性共比与独有维度短板提示；④给出是否双赛道申报的建议。

**联动产物模板**：
```
【跨赛道联动评估】实践：<名称>
- A1 数据要素赛道评分：__/100（短板：数据要素应用深度 __）
- A2 企业满意赛道评分：__/100（短板：企业满意度 __）
- 跨赛道综合分（0.5/0.5）：__/100
- 共比维度：实效性 A1__ / A2__；创新性 A1__ / A2__；示范性 A1__ / A2__
- 联动建议：<是否建议双赛道申报 / 优先补强哪一独有维度>
```
